# When to escalate

Escalate when you lack access or authority, the SLA is at risk, several users show the same fault, a vendor is needed, or you have spent the allowed time without progress.

Escalate **immediately** to security for: phishing clicks, lost or stolen devices, unexpected MFA prompts, malware alerts, or any request to skip identity verification.

Use `templates/escalation-handoff.md` and attach evidence: error text, screenshots, command output, timeline and steps tried.
